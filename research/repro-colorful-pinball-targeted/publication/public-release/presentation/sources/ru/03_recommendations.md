# Recommendations for the authors

- Expose an explicit external seed interface.
- Publish per-seed raw outputs and exact repeat counts.
- Document aggregation rules, environment details, and any normalization steps in machine-readable form.
- Ship a reproducibility script that rebuilds the evidence bundle end to end.

## What this deck does not do

- It does not publish the research.
- It does not change the study outcomes.
- It does not rerun the benchmark.
- It does not introduce external scientific evidence.
