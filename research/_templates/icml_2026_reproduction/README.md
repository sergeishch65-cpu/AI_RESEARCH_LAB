# ICML 2026 reproduction template

Этот шаблон предназначен для будущего challenge study после выбора статьи.

- Не содержит выбранный paper_id.
- Не создаёт реальное воспроизведение статьи.
- Готовит безопасную структуру для claims, plans, experiments, results, figures, logs, logbook и challenge metadata.
