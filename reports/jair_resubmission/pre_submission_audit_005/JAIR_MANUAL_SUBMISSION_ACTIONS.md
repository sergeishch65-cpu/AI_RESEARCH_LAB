# JAIR Manual Submission Actions

This file lists the actions that still must be completed manually in the JAIR submission system. It does not change the manuscript.

| No. | Manual action | Why it is manual | Prepared local material | Target field / stage | Status |
|---:|---|---|---|---|---|
| 1 | Confirm originality and unpublished status in the submission wizard | JAIR requires the author to assert this in the system. | Final manuscript and final PDF are already prepared. | Submission declaration checkbox | Pending manual action |
| 2 | Confirm there is no simultaneous submission elsewhere | JAIR requires this in the system. | Final manuscript and resubmission audit package are already prepared. | Submission declaration checkbox | Pending manual action |
| 3 | Enter the three mandatory Submission Questions | The answers must be copied into the online form. | `reports/jair_resubmission/corrective_003/JAIR_SUBMISSION_QUESTIONS.md` | Last section of submission form | Pending manual action |
| 4 | Enter article metadata in the form | The system needs typed metadata, not just local files. | Title, author, affiliation, email, abstract in the manuscript. | Title / authors / contact / abstract fields | Pending manual action |
| 5 | Upload the final PDF | The actual upload happens in the submission system. | `submission/jair_v3/manuscript/ERROR_PERSISTENCE_V3_MANUSCRIPT.pdf` | PDF upload step | Pending manual action |
| 6 | Upload any source archive if requested later | This is only required after acceptance or if the editor requests it. | Source tree is already preserved locally. | Post-acceptance production stage | Deferred, not current-stage blocker |
| 7 | Sign source-code release form if code is later placed in an online appendix | This is a later-stage action that depends on how the editor handles appendices. | Code and data are preserved locally, but no public archive is frozen. | Post-acceptance release workflow | Deferred, conditional |
| 8 | Final click on Submit | This is the last system action and cannot be represented by a local file. | Everything needed for the form is already prepared. | Submission wizard final step | Pending manual action |
